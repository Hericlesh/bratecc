# BRATECC Connect AI

Sistema de Matching Inteligente para BRATECC - Câmara de Comércio Brasil-Texas.

## 🚀 Deploy

### Instalação

```bash
npm install
```

### Desenvolvimento

```bash
npm run dev
```

### Build para Produção

```bash
npm run build
```

### Preview do Build

```bash
npm run preview
```
